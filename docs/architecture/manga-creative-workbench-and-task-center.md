## 本次交付

- 项目概览使用紧凑项目头、阶段导航、章节与镜头统计、任务状态和最近产物。
- 剧本与章节编辑使用章节目录、正文编辑区和工具栏，保留导入、保存、解析、章节提案和分镜提案。
- 分镜工作台使用章节及场景目录、镜头字段编辑、图片及视频区域、底部镜头条。章节、场景、镜头和媒体标签通过 URL 恢复。
- 聊天与手动任务共用 AI 创作任务中心。会话正文读取 Message 投影，执行详情读取 Journal，审批和产物使用各自服务端快照。
- 配置编辑默认显示保存密钥的脱敏值，眼睛按钮显式读取明文，“更换密钥”进入新输入状态。仅查看后保存不会覆盖密钥。

角色、场景、道具资产栏和真实 Skill 执行尚未接入，本次不展示虚构执行记录。

## 一次请求的链路

```text
聊天 / 章节工具栏 / 镜头媒体表单
  → Creative Run API
  → RunAdmissionService 冻结目标、权限、Blueprint 和幂等标识
  → 同事务写入 Run、Root Step、Dispatch Outbox
  → 提交后立即派发，扫描补偿遗漏的调度
  → CreativeStepClaimService 原子领取并递增 ownerEpoch
  → 领取事务提交前设置初始 lease，避免开始事件落库消耗执行租期
  → AgentCreativeStepExecutor 立即开启独立心跳
  → 预算与状态预检 → KernelHandle → HarnessLease
  → MeteredModelFactory 持久化调用账本并约束单次尝试、总时限、无响应时限
  → 供应商流 → 连续文本合并 → 有界串行持久化队列
  → ownerEpoch 围栏校验 → Event Journal → Message 投影 → SSE 唤醒
  → 页面按快照及事件游标恢复
```

工具生成 ChangeSet 草稿后，先结束模型流并释放 HarnessLease、KernelHandle，再进入审批检查点。用户批准后仍使用原 Blueprint Snapshot 恢复；媒体作业在供应商执行和转存期间不占用 Harness。

失败或取消后，“重新生成”创建新的 requestId 与 Run，原执行、提案、审批记录保留。外部媒体调用不会因网络结果不明确而自动重复提交。

## 执行与故障边界

### 租约

心跳覆盖 Blueprint 恢复、预算预留、状态预检、Kernel 获取、模型调用和终态提交。租约调度资源与模型、Outbox 和事件写入隔离。

异常处理只使用最初领取的 Claim。已运行的旧执行器不能查询新代次后提交失败，也不能越过 ownerEpoch 围栏写事件或结束步骤。

租约失联时，如果该代次已经调用模型，且没有草稿、协作计划、结构化结果或外部作业恢复检查点，则收敛为 `MODEL_RESULT_UNCERTAIN`。用户核对后可新建请求，恢复器不会隐式再次计费。尚未发起模型调用的步骤仍可按原恢复规则重新调度。

### 文本持久化

`CreativeAgentEventBuffer` 合并连续文本，达到 1024 个 UTF-8 字节或首个未提交片段等待 200ms 时投递。工具事件、结束和错误之前先冲刷文本。

数据库写入在自定义 Scheduler 中串行进行，预取队列为 32 个合并事实。模型响应边界另设 512 项有界缓冲。错误延迟到已有队列事实处理之后传播，不会静默丢掉错误前已经接收的文本；过载明确收敛为 `EVENT_BACKPRESSURE_OVERFLOW`。

子 Agent 的工具事实也写入 Journal，但子 Agent 内部文本不投影为主助手正文。公开工具摘要由 `CapabilitySummary` 在领域工具内生成，摘要缓存不接收原始参数和完整结果。

### 时限和分类

| 设置 | 默认值 | 含义 |
| --- | --- | --- |
| `manga.creative.operations.call-timeout` | 2m | 普通操作单次模型调用总时限 |
| `MANGA_STORYBOARD_MODEL_TIMEOUT` | 5m | 章节分镜及所属协作步骤单次模型调用总时限 |
| `MANGA_MODEL_IDLE_TIMEOUT` | 2m | 连续未收到供应商响应数据的最长时间 |

持续输出不会延长总时限。无响应计时位于模型响应入口，文本数据库写入在下游隔离队列中执行。SDK 的执行选项同时设置调用时限与 `maxAttempts=1`。

公开错误区分总时限、无响应、认证、限流、协议、租约丢失、结果不确定和事件队列过载。日志包含 Run/Step/调用标识、代次、首包与总耗时、领取和续租耗时、事件写入耗时；不记录密钥、提示词或完整供应商响应。

## HTTP 契约

| 接口 | 说明 |
| --- | --- |
| `POST /api/v1/ai-provider-configs/{id}/reveal-key` | 仅配置所有者可读，响应 `Cache-Control: no-store`；明文只保留在当前弹窗内存 |
| `GET /api/v1/creative-runs/{runId}/timeline?afterSequence=0&limit=100` | 事件序号分页，limit 上限 200，所有权校验与快照读取在同一服务事务中执行 |
| `GET /api/v1/creative-runs?projectId=...&beforeId=...` | 手动任务历史及最新活动任务，包含剧本解析；省略 projectId 查询认证用户全部项目 |
| `GET /api/v1/generation-jobs?projectId=...&shotId=...&mediaType=IMAGE&beforeId=...` | 在分页前按镜头和 IMAGE/VIDEO 审批类型过滤，保留既有 Run 与会话筛选 |
| `GET /api/v1/generation-jobs/{jobId}/download` | 下载前复核所有权并刷新链接，OSS 使用包含 attachment 响应头的签名，响应禁止缓存 |

时间线分页返回 `items`、`throughSequence`、`recoveryWatermark`、`hasMore`。前者是已扫描水位，后者是查询快照内日志最高序号。隐藏的内部文本也推进扫描游标。

公开时间线条目版本为 2，包含 Step、父步骤、原始执行代次、固化 Agent 名称和版本、动作状态、时间、安全摘要和应用内资源链接。旧工具事件没有摘要或代次时仍可按名称、状态、时间展示，缺失工具终态时根据服务端步骤或 Run 终态收敛为中断。

既有 SSE Envelope 不改结构。新工具和失败载荷增加版本及可选字段，原有三字段工具载荷继续兼容。不会公开 Blueprint 系统提示词、模型推理过程或原始供应商结果。

## 前端恢复与导航

- 任务中心约占桌面视口八成，窄屏全屏。目录支持当前项目过滤及历史游标。
- 只挂载当前选择任务的详情和 SSE。SSE 只唤醒刷新，快照更新串行执行；关闭或切换后释放订阅与定时器。
- 一轮时间线分页全部成功才提交新游标。后续页网络失败时保留旧游标，重试通过稳定事件标识去重。
- 刷新后恢复会话、任务标签和 Run 选择；正文、工具状态、审批和产物以服务端数据为准。
- 镜头 URL 支持 `chapter`、`scene`、`shot`、`media`。未保存修改会保护章节切换、控制台导航、浏览器后退、刷新和关闭页面。
- 图片继续使用已有采用预览与 revision 校验，视频提供播放和下载。生成必须明确选择已有的对应媒体类型模型，计费提交仍需审批。
